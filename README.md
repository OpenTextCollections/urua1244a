# Open Text Collections #9
## Even texts

This collection features 10 texts from two different dialects of the Uruangnirin language, spoken in Indonesia.

The texts were narrated by Kamal Kanabaraf-Yorkuran, Badarudin Kanabaraf,Badarudin Kanabaraf, Saleh Patur, and Lukman Kanabaraf, and compiled by Eline Visser.

The files in this repository contain the texts in the CLDF format. A human readable version of
the book is available under the name "Life and death on Karas: Ten Uruangnirin texts " at https://zenodo.org/records/19091196
